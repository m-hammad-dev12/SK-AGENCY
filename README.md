## 🚀 Business Overview

**SK AGENCY** helps customers discover quality products, connect with trusted service providers, request assistance, and generate business enquiries across international markets.

### Main Business Categories
1. **Car Key Services**: Car key replacement, key duplication, remote key assistance, and programming enquiries.
2. **Appliance Repair**: Service coordination for washing machines, refrigerators, microwaves, and household appliances.
3. **Online Product Selling**: Curated product discovery, specifications, sourcing, and customer assistance.
4. **Customer Lead Generation**: Routing customer requests and connecting seekers with qualified service providers.

## ✨ Features & Functionality

- **Strict Authentic Media Policy**: Features ONLY the authentic customer service photograph (`assets/uploaded-image.jpg`), with zero third-party stock photos or AI-generated imagery.
- **Sticky Navigation Bar**: Blur backdrop filter with dynamic scrollspy and accessible mobile drawer menu.
- **Hero Section**: High-contrast navy overlay with typography, animated badge, and direct call-to-actions.
- **Dynamic Category Pre-Fill**: Clicking *"Enquire Now"* or *"Explore"* on any service or product automatically selects the category in the form, updates the sub-services dropdown, pre-fills the message, and scrolls directly to the enquiry section.
- **Real-Time Client Validation & Clean Reset**: Full Name, Phone, Email, Category, and Message field checking with instant error clearing on input and complete reset restoring default states.
- **Instant WhatsApp Generator**: Formats a WhatsApp enquiry with all customer inputs pre-encoded and opens `https://wa.me/923701604764?text=...`.
- **FAQ Accordion**: Single/multi-expand accordion with `aria-expanded` accessibility.
- **High-Impact Conversion Banners**: Direct telephone (`tel:+923701604764`) and WhatsApp chat banners.
- **Full Responsiveness**: Tested at 360px, 390px, 430px, 768px, 1024px, 1366px, 1440px, and 1920px with `prefers-reduced-motion` compliance.

## 💻 How to Run Locally

Because this project is built entirely with vanilla web standards, it runs directly in any modern browser without needing Node.js or build steps.

### Option 1: Direct File
Simply open `index.html` in your web browser.

### Option 2: Local Python Server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
